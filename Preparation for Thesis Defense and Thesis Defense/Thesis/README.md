# Выпускная квалификационная работа

Самостоятельное исследование или разработка по направлению магистратуры: постановка задачи, обоснование методов, получение результатов и их представление в связном научном тексте.

## Структура

- Титульный лист.
- Задание.
- Аннотация.
- Содержание.
- Основной текст работы.
- Список использованных источников.

## Содержание исследования

Обоснование актуальности темы, цели и задач; анализ научной литературы; выбор методов; разработка моделей, алгоритмов или программных средств; экспериментальная оценка; выводы.
