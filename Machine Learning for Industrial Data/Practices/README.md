# Практические занятия

Практикум ML in Industry 2026 развивает Plant Engineer Assistant — LLM-систему для работы с журналами обслуживания, регламентами и данными оборудования.

## Содержание

- Структурированное извлечение данных из журналов обслуживания.
- Оценка LLM-систем на эталонных примерах и анализ ошибок.
- Обработка промышленных документов: текст, OCR, таблицы и визуальные модели.
- Синтетические данные, ноутбуки, сохранённые ответы моделей и эталонные результаты; режим replay позволяет воспроизводить примеры без обращения к модели.

## Работы

- [Структурированное извлечение журналов обслуживания](Structured%20Extraction/README.md) — Практика 2026: преобразование записей о техническом обслуживании в структурированные данные.
- [Оценка качества LLM-системы](LLM%20Evaluation/README.md) — Практика 2026: построение evaluation harness для систем промышленного помощника.
- [Разбор промышленных документов](Industrial%20Document%20Parsing/README.md) — Практика 2026: сравнение способов чтения промышленного регламента и подготовки его содержимого для LLM-системы.
