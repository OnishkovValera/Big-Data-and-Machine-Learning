# Разбор промышленных документов

Практика 2026: сравнение способов чтения промышленного регламента и подготовки его содержимого для LLM-системы.

## Содержание

- Текстовый слой, OCR, Docling и визуально-языковые модели.
- Метрики чтения документов и обработка таблиц.
- Чертежи и таблички оборудования как визуальные входные данные.
- Хранилище фрагментов с метаданными и редакциями документов.
- Небольшой оценочный эксперимент с парным сравнением.
