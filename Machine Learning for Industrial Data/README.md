# Machine Learning for Industrial Data / Методы машинного обучения для обработки промышленных данных

Применение машинного обучения в промышленности и IoT: от хранения и обработки сенсорных данных до интеллектуальных помощников и интеграции моделей в производственные процессы.

## Материалы курса

- [Лекции](Lectures/README.md).
- [Практические занятия](Practices/README.md).

## Что изучают

- Сенсорные данные: управление и хранение, вычислительная обработка, обучение моделей и разработка алгоритмов.
- Интеллектуальные профессиональные помощники: интеграция знаний, few-shot и zero-shot обучение, RLHF.
- Генерация синтетических данных и построение соответствующих пайплайнов.
- Промышленные задачи с дополненной реальностью: сопровождение операций, ускорение процедур, автоматизированная проверка и контроль качества.
- Раздел AI Differentiated Programming: самоорганизующиеся системы обучения и составные архитектуры глубокого обучения.
- ML для компьютерного инжиниринга: физическая правдоподобность моделей, условная генерация сценариев и объединение модальностей.
- Проектирование инфраструктуры больших данных и обработка полуструктурированных данных средствами ИИ.

## Подготовка

Методы оптимизации, машинное обучение, теория вероятностей, линейная алгебра и математическая статистика.
