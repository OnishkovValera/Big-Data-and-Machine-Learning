# Эссе о личных ресурсах

[К разделу](../README.md) · [Описание предмета](../../README.md)

Эссе о ресурсах в профессии и жизни рассматривает личностные ресурсы, факторы достижения результатов в учебе и работе, а также ресурсы окружающей среды. Объем — 3–5 страниц; структура включает введение, основную часть и заключение. Работа представляется в коротком сообщении на 2–3 минуты.
