# Коллоквиум: развитие группы

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа сопоставляет текущую ситуацию в группе с этапами формирования, конфликта, установления норм, получения результата и завершения. Обсуждаются групповые роли и шаги к поставленной цели.
