# Коллоквиум: стресс и саморегуляция

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа включает анализ стрессовых событий и привычных способов совладания. Индивидуальные выводы обсуждаются в группе; результатом становятся перечень стрессовых ситуаций и список стратегий саморегуляции.
