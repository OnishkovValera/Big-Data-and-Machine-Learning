# Коллоквиум: сила воли

[К разделу](../README.md) · [Описание предмета](../../README.md)

Парное упражнение связывает долгосрочные цели с действиями, которые необходимо начать или прекратить. Обсуждаются возможности силы воли и конкретные шаги к желаемому результату.
