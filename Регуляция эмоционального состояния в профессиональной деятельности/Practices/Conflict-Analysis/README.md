# Кейс: анализ конфликта

[К разделу](../README.md) · [Описание предмета](../../README.md)

Групповой кейс разбирает конфликт на примере «Сказки о рыбаке и рыбке». Анализ включает предпосылки, предмет, повод, причины, участников, динамику, функции и способы разрешения конфликта. Группа представляет решение и обсуждает выводы.
