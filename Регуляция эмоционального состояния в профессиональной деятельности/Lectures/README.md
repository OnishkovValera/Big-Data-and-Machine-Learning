# Лекции

[Описание предмета](../README.md)

Четыре часа лекций посвящены эмоциональным процессам и состояниям в профессиональной деятельности, работоспособности и психологии стресса.

## Темы

- Эмоциональные процессы и состояния, работоспособность в течение дня.
- Стресс, негативные психические состояния и способы совладания.
