# Итоговая работа

[Описание предмета](../README.md)

Итоговая работа выполняется в одном из трех форматов: план научной статьи, видео о научной области или план грантовой заявки. Предусмотрено взаимное оценивание пяти работ с обратной связью.

## Работы

- [План научной статьи](Scientific-Article-Outline/README.md) — Работа объемом 2–3 страницы строится по IMRaD, содержит аннотацию, содержание основных разделов и ссылки на научные источники.
- [Видео о научной области](Science-Video/README.md) — Видео длительностью более двух минут представляет научную область через три достоверных факта со ссылками на источники.
- [План грантовой заявки](Grant-Application-Outline/README.md) — Работа объемом 2–3 страницы описывает конкретную грантовую программу, ее требования, актуальность проекта, ожидаемые результаты и предварительный бюджет.
