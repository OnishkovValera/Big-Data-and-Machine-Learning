# План грантовой заявки

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа объемом 2–3 страницы описывает конкретную грантовую программу, ее требования, актуальность проекта, ожидаемые результаты и предварительный бюджет. Мотивационная часть объясняет научную или общественную пользу проекта и возможности команды.
