# Видео о научной области

[К разделу](../README.md) · [Описание предмета](../../README.md)

Видео длительностью более двух минут представляет научную область через три достоверных факта со ссылками на источники. Содержание раскрывает пользу области для общества и связь автора с исследованием; выступление использует приемы самопрезентации.
