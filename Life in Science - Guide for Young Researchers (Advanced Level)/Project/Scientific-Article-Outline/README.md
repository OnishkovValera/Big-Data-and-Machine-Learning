# План научной статьи

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа объемом 2–3 страницы строится по IMRaD, содержит аннотацию, содержание основных разделов и ссылки на научные источники. Включает обоснование выбора журнала с учетом его требований и библиографических показателей.
