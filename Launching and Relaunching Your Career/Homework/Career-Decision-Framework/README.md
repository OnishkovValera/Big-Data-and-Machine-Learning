# Модель карьерного решения

[К разделу](../README.md) · [Описание предмета](../../README.md)

Для карьерного решения применяется один из подходов: материалы 80,000 Hours, модель 3E или Ikigai. Работа связывает выбранную модель с интересами, компетенциями и профессиональными возможностями.
