# Анализ карьерной среды

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа применяет два инструмента из PEST, SWOT и сравнительного анализа к карьерной ситуации. Рассматриваются внутренние факторы и изменения внешней среды, влияющие на выбор профессионального пути.
