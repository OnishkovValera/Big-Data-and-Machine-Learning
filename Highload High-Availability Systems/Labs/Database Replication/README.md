# Репликация базы данных

Пример лабораторной работы 2025 года: PostgreSQL master–replica с потоковой репликацией и распределением запросов чтения.

## Содержание

- Основной узел PostgreSQL и read-only replica.
- Streaming replication.
- Распределение доли чтений и наблюдение за базой через метрики.
