# Масштабирование и балансировка

Пример лабораторной работы 2025 года: сравнение конфигураций масштабирования сервиса и распределение нагрузки через Nginx.

## Содержание

- Вертикальное и горизонтальное масштабирование.
- Nginx и балансировка запросов.
- Длительная нагрузка и сценарий тестирования 1600 RPS.
