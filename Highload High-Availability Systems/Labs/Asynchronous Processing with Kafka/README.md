# Асинхронная обработка с Kafka

Пример лабораторной работы 2025 года: синхронная обработка HTTP-запросов и асинхронная передача работы через Kafka.

## Содержание

- Kafka producer и consumer.
- Отличия синхронного запроса и отправки сообщения в очередь.
- Метрики запросов, произведённых и обработанных сообщений.
