# Кэширование и объединение запросов

Пример лабораторной работы 2025 года: Redis-кэш перед PostgreSQL и обработка параллельных обращений к одному ключу.

## Содержание

- Паттерн cache-aside и срок жизни TTL.
- Объединение запросов для защиты от thundering herd.
- Метрики попаданий, промахов и времени запросов к базе.
