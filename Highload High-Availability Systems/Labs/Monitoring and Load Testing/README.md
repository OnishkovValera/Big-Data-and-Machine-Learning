# Мониторинг и нагрузочное тестирование

Пример лабораторной работы 2025 года: сервис Flask в Docker с нагрузочным тестированием и наблюдением за метриками.

## Содержание

- Flask и контейнерное окружение Docker.
- Генерация нагрузки с k6.
- Prometheus, Grafana и правила оповещений.
