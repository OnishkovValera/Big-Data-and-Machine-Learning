# Карта эмпатии

[К разделу](../README.md) · [Описание предмета](../../README.md)

Карта эмпатии составляется для ситуации из собственной жизни по вопросам шаблона. Работа связывает наблюдаемые обстоятельства с эмоциями и потребностями участников общения и сопровождается изучением материала о природе эмпатии.
