# Эмпатическое высказывание

[К разделу](../README.md) · [Описание предмета](../../README.md)

Практическое упражнение состоит из эмпатического высказывания для выбранной ситуации и его обсуждения в паре. Обратная связь касается эмоционального воздействия формулировки и понимания позиции собеседника.
