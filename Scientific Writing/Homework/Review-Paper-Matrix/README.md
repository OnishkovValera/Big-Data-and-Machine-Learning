# Review Paper Matrix

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа с матрицей обзорной статьи систематизирует содержание научных источников для обзора литературы. Связанные темы — структура review paper, анализ публикаций и организация материала по исследовательскому вопросу.
