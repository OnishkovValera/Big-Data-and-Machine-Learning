# CV и мотивационное письмо

[К разделу](../README.md) · [Описание предмета](../../README.md)

Письменная работа представляет опыт кандидата и его мотивацию для академической возможности. Мотивационное письмо включает вступление, основную часть с конкретными примерами компетенций и заключение; оцениваются структура, стиль и язык.
