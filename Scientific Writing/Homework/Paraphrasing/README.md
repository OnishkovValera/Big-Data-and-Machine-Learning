# Перефразирование

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа передает содержание исходного фрагмента другими языковыми средствами, сохраняя его смысл. Темы связаны со связностью текста, корректным использованием источников и разграничением перефразирования и плагиата.
