# Academic Bio

[К разделу](../README.md) · [Описание предмета](../../README.md)

Краткая академическая биография для научной коммуникации: сведения об образовании, специализации и профессиональной деятельности. Текст использует третье лицо, связное изложение и формальный стиль; объем зависит от формата задания.
