# Практические занятия

Реализация и сравнение алгоритмов оптимизации, исследование эффективности и многокритериальных решений.

## Содержание

- Градиентные и неградиентные методы оптимизации.
- Популяционные алгоритмы и настройка моделей.
- Вычислительно дорогие целевые функции, суррогатное моделирование и робастность.
- Многокритериальная постановка задачи, ранжирование и множество Парето.
