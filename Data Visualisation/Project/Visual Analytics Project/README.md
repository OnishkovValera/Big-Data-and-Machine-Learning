# Проект визуальной аналитики

Итоговый проект соединяет обработку реального набора данных с разработкой визуального представления и исследованием результатов. Тематическая основа — веб-визуализации и высокопроизводительная графика.

## Содержание

- Представление структуры и свойств набора данных.
- Подготовка данных к визуализации.
- Выбор графических средств и интерактивных элементов.
- Визуальный анализ результатов.

## Пример

[Проект анализа ДТП](https://github.com/BubbleNeumann/itmo-masters/blob/master/sem1_datavis_proj.ipynb) использует pandas, Plotly, Matplotlib и seaborn. Набор данных проекта связан с дорожными происшествиями.
