# Практика 3. Интерактивная графика

Построение визуализаций, в которых взаимодействие с графиком раскрывает дополнительные сведения о данных. Рассматривается связь отображения и пользовательских действий.

## Содержание

- Интерактивные графики и элементы взаимодействия.
- Изменение представления данных при действиях пользователя.
- Веб-графика и интерактивное отображение пространственных данных.
