# Практика 1. Основы визуализации

Основы визуального представления данных и зрительного восприятия. Работа объединяет вводные понятия визуализации с восприятием, ощущениями и цветом.

## Содержание

- Связь данных, изображения и интерпретации.
- Особенности зрительного восприятия.
- Цветовые шкалы и использование цвета при представлении информации.
