# Практика 2. Обработка данных

Подготовка данных к визуальному представлению и выбор графического кодирования. Основные темы — типы данных, каналы, символы и формы.

## Содержание

- Типы данных и подходящие способы их отображения.
- Каналы визуального кодирования.
- Символы, формы и связь структуры данных с графическим представлением.
