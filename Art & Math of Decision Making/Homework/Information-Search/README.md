# Поиск информации для решения

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа посвящена сбору мнений и данных для конкретного решения. Опрос включает не менее семи вопросов двум разным людям; поиск данных — два интернет-источника. Итогом становятся анализ источников и пять критериев принятия решения.
