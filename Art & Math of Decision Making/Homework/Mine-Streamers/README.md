# Критерии пересмотра решения

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа задает три измеримых сигнала, при которых принятое решение следует пересмотреть. Для каждого сигнала указываются показатель, срок и частота проверки. Отдельно определяется участник, помогающий отслеживать эти сигналы.

## Ресурсы

- [Страница дисциплины](https://my.itmo.ru/programs/38244).
