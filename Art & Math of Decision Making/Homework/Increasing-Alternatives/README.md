# Расширение набора альтернатив

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа рассматривает три привычные ситуации с автоматическим решением. Для каждой определяются удовлетворяемая потребность и три альтернативных способа ее удовлетворить. Результат включает наблюдения за трехдневной проверкой альтернатив и три вывода.
