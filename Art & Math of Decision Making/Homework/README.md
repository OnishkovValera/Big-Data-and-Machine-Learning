# Домашние задания

[Описание предмета](../README.md)

Письменные и прикладные работы связывают инструменты принятия решений с жизненными и профессиональными ситуациями. Итоговое портфолио объединяет примеры решений и анализ собственного подхода.

## Работы

- [Планирование эксперимента](Experiment/README.md) — Эссе описывает ситуацию, для которой решение можно проверить экспериментально.
- [Расширение набора альтернатив](Increasing-Alternatives/README.md) — Работа рассматривает три привычные ситуации с автоматическим решением.
- [Поиск информации для решения](Information-Search/README.md) — Работа посвящена сбору мнений и данных для конкретного решения.
- [Критерии пересмотра решения](Mine-Streamers/README.md) — Работа задает три измеримых сигнала, при которых принятое решение следует пересмотреть.
- [Многокритериальный анализ решения](Multi-Criteria-Analysis/README.md) — Разбор кейса с применением двух инструментов: взвешенной системы оценок и метода попарных сравнений.
- [Портфолио принятия решений](Decision-Making-Portfolio/README.md) — Портфолио описывает индивидуальный подход к решениям в простых, сложных и хаотических системах, примеры и последствия выбора.
