# Динамические очереди

Работы по моделированию динамических очередей и систем массового обслуживания.

## Содержание

- Поступление заявок и их обслуживание.
- Состояния очереди и изменение нагрузки во времени.
- Экспериментальное исследование модели и статистический анализ результатов.
- Python-ноутбуки и реализации на Go в учебном репозитории.
