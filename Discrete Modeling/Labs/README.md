# Лабораторные работы

Имитационное моделирование процессов со случайными событиями: построение модели, вычислительный эксперимент и анализ результатов.

## Содержание

- Математическая модель процесса и выбор способа представления состояний.
- Эксперименты с параметрами, анализ чувствительности и неопределённости.
- Системы массового обслуживания и динамические очереди.
- Статистическая обработка и визуализация результатов, верификация и валидация модели.
