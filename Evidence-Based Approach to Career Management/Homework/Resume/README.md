# Резюме

[К разделу](../README.md) · [Описание предмета](../../README.md)

Резюме объемом 1–2 страницы представляет образование, опыт, задачи и результаты работы или практики, дополнительные занятия и навыки. Содержание и акценты связываются с требованиями выбранной вакансии.
