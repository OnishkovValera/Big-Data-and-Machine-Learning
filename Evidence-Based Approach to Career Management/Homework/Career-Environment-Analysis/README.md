# Анализ карьерной среды

[К разделу](../README.md) · [Описание предмета](../../README.md)

Для оценки карьерной ситуации применяются два инструмента из трех: PEST, SWOT и сравнительный анализ. Работа раскрывает внутренние сильные и слабые стороны, внешние возможности и угрозы либо сравнительные преимущества.
