# Домашние задания

[Описание предмета](../README.md)

Домашние работы включают анализ неприятного события через факты, эмоции, интерпретацию, потребности и действия; перечни занятий, дающих и отнимающих энергию; план развития трех навыков устойчивости. Результат — письменная рефлексия и обоснованные выводы по выбранным ситуациям.
