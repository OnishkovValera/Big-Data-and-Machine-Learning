# Самопрезентация и питч идеи

[К разделу](../README.md) · [Описание предмета](../../README.md)

Два видео по 1,5–2 минуты: самопрезентация для нетворкинга и питч идеи для инвесторов или жюри. Работы демонстрируют ясную структуру, уверенную подачу и соответствие цели общения.
