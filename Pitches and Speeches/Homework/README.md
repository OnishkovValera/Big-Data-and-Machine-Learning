# Домашние задания

[Описание предмета](../README.md)

Видеоработы посвящены самопрезентации, питчу идеи и адаптации одной научной темы к разным аудиториям. Оцениваются структура, убедительность и соответствие формата выступления его цели.

## Работы

- [Самопрезентация и питч идеи](Self-Presentation-and-Idea-Pitching/README.md) — Два видео по 1,5–2 минуты: самопрезентация для нетворкинга и питч идеи для инвесторов или жюри.
- [Структура выступления](Speech-Structure/README.md) — Одна тема научной работы представляется в двух видео по две минуты: для профессионального сообщества и широкой фестивальной аудитории.
