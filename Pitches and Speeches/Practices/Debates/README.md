# Дебаты

[К разделу](../README.md) · [Описание предмета](../../README.md)

Парная работа строится вокруг тезиса и трех аргументов с подкрепляющими примерами. Партнер задает вопросы, после чего участники меняются ролями. Результат включает аргументированную переписку и ответы на вопросы.

## Ресурсы

- [Страница дисциплины](https://my.itmo.ru/programs/38248).
