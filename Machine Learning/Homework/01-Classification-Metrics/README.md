# Домашняя работа №1. Метрики качества классификации

Сравнение качества классификации через предсказания модели, истинные метки и типы ошибок.

## Основные вопросы

- Матрица ошибок и смысл ошибок разных типов.
- Accuracy, precision, recall и F-мера.
- Изменение результата при выборе порога классификации.
- ROC- и PR-представления качества, работа с дисбалансом классов.
