# Домашняя работа №2. Обработка естественного языка

Применение машинного обучения к текстовым данным и исследование их признаковых представлений.

## Основные вопросы

- Подготовка и нормализация текстов.
- Построение признаков на основе слов и TF-IDF.
- Выбор модели для текстовых данных.
- Сравнение качества и разбор ошибок.
