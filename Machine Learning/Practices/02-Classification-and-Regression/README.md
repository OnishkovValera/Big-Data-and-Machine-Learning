# Классификация и регрессия

Обучение базовых моделей и сопоставление их предсказаний с целевыми значениями.

## Основные вопросы

- Постановка задачи и выбор целевого признака.
- Подготовка обучающей и тестовой выборок.
- Обучение нескольких семейств моделей.
- Сравнение моделей по метрикам и анализ типичных ошибок.
