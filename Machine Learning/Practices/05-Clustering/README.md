# Кластеризация

Поиск групп похожих объектов и интерпретация структуры данных.

## Основные вопросы

- Подготовка признаков и выбор расстояния.
- Сравнение алгоритмов кластеризации.
- Изучение влияния числа кластеров и параметров метода.
- Визуализация групп и характеристик их объектов.
