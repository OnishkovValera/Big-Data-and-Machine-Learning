# Метрики качества классификации

Оценка классификаторов с учётом типов ошибок и выбранного порога решения.

## Основные вопросы

- Confusion matrix: TP, FP, TN и FN.
- Accuracy, precision, recall и F-мера.
- Порог классификации, ROC-AUC и precision–recall.
- Дисбаланс классов и различия между метриками.
