# Обработка текста

Построение признаков из текстов и применение к ним алгоритмов машинного обучения.

## Основные вопросы

- Токенизация и нормализация документов.
- Мешок слов, n-граммы и TF-IDF.
- Обучение текстового классификатора или сравнение текстовых представлений.
- Оценка качества и анализ ошибок на текстовых данных.
