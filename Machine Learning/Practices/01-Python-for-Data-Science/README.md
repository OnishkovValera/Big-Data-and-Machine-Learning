# Python для Data Science

Работа с данными и базовыми инструментами вычислительного эксперимента.

## Основные вопросы

- Массивы NumPy и таблицы pandas.
- Загрузка данных, проверка типов и обработка пропусков.
- Описательная статистика и простые графики.
- Организация вычислений в Jupyter Notebook или Google Colab.
