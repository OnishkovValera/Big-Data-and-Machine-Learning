# Обучение без учителя

Методы поиска групп и компактных представлений данных без заранее заданных целевых ответов.

## Основные вопросы

- Метрики расстояния и подготовка признаков для кластеризации.
- K-means, иерархическая кластеризация и плотностные подходы.
- Сравнение кластеризаций и интерпретация полученных групп.
- Понижение размерности: PCA, SVD и визуализация многомерных данных.
- Связь скрытого представления объектов с устройством исходных признаков.
