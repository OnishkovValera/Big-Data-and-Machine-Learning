# Методы оптимизации

Минимизация функции потерь при обучении моделей и влияние оптимизатора на ход обучения.

## Основные вопросы

- Функция потерь, градиент и направление обновления параметров.
- Градиентный спуск, стохастические и mini-batch обновления.
- Шаг обучения, сходимость и поведение кривой потерь.
- Momentum, RMSProp и Adam.
- Регуляризация и различие между снижением тренировочной ошибки и обобщением.
