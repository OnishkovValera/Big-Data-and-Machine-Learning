# Анализ последовательностей и прогнозирование

Моделирование данных, в которых порядок наблюдений влияет на результат: временные ряды и рекуррентные сети.

## Основные вопросы

- Лаговые признаки, окна наблюдений и горизонт прогноза.
- Разделение временных данных с сохранением хронологии.
- Рекуррентное состояние, RNN, LSTM и GRU.
- Построение и сравнение прогнозных моделей.
- Ошибки прогнозирования и проверка качества на последовательных временных интервалах.
