# Предобработка данных и обзор алгоритмов

Подготовка признаков и знакомство с основными семействами моделей для классификации и регрессии.

## Основные вопросы

- Типы признаков, пропуски, категориальные значения и one-hot encoding.
- Масштабирование числовых признаков и его влияние на расстояния и оптимизацию.
- Разделение данных на обучающую, валидационную и тестовую части.
- Линейные модели, ближайшие соседи, деревья решений и ансамбли.
- Обучение преобразований только на тренировочных данных и предотвращение утечки информации.
