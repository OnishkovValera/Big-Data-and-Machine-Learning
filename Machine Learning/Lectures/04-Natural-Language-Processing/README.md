# Обработка естественного языка

Переход от текстовых документов к признаковым представлениям и моделям машинного обучения.

## Основные вопросы

- Токенизация, нормализация текста, стоп-слова, stemming и лемматизация.
- Мешок слов, n-граммы и TF-IDF.
- Векторные представления слов и документов.
- Классификация текстов, поиск похожих документов и сравнение текстовых представлений.
- Оценка качества текстовых моделей и влияние предобработки.
