# Многослойный перцептрон и backpropagation

Устройство полносвязной нейросети и вычисление градиентов её параметров через правило цепочки.

## Основные вопросы

- Линейный слой, смещения и функции активации.
- Прямой проход и вычисление функции потерь.
- Обратный проход, локальные производные и накопление градиентов.
- Обновление весов и проверка размерностей промежуточных величин.
- Численная проверка градиентов, затухание градиента и переобучение.
