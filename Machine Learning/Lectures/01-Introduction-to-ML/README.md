# Введение в машинное обучение

Машинное обучение изучает алгоритмы, которые улучшают качество решения задачи на основе данных и накопленного опыта.

## Задача, опыт и качество

- **T — задача:** что требуется предсказывать или какую структуру данных необходимо определить.
- **E — опыт:** данные и, при наличии, целевые ответы, используемые для обучения.
- **P — мера качества:** численная характеристика результата работы алгоритма.

При обучении с учителем используются пары «объект — целевой ответ». В классификации ответом служит класс, в регрессии — числовое значение. При обучении без учителя готовых ответов нет: методы выявляют группы, зависимости и компактные представления объектов.

## Вероятностный взгляд на обучение

Для событий A и B совместная вероятность связана с условными вероятностями:

$$
p(A,B)=p(A\mid B)p(B)=p(B\mid A)p(A).
$$

Если D — данные, а θ — параметры модели, формула Байеса принимает вид:

$$
p(\theta\mid D)=\frac{p(D\mid\theta)p(\theta)}{p(D)}.
$$

- **p(θ)** — априорное распределение параметров.
- **p(D | θ)** — правдоподобие: насколько наблюдаемые данные согласуются с выбранными параметрами.
- **p(θ | D)** — апостериорное распределение после учёта данных.
- **p(D)** — нормирующий множитель.

## MAP-оценивание

MAP-оценка максимизирует апостериорную плотность, а для дискретных параметров — апостериорную вероятность:

$$
\hat{\theta}_{MAP}=\arg\max_{\theta}p(D\mid\theta)p(\theta).
$$

При фиксированных данных множитель p(D) не зависит от параметров и не влияет на положение максимума. Полный байесовский подход сохраняет распределение параметров и обновляет его при появлении новых наблюдений.

Пример — регрессия стоимости квартиры по её площади. Параметры задают вид прогнозной зависимости, правдоподобие описывает согласованность наблюдений с моделью ошибок, а априорное распределение выражает исходные предположения о параметрах.
