# Онлайн-тесты

В курсе предусмотрены три онлайн-теста. Для допуска к экзамену необходимо пройти любые два теста и успешно сдать три домашние работы из четырёх. Для автоматической оценки «4C» требуются все три теста и все четыре домашние работы, выполненные вовремя.
