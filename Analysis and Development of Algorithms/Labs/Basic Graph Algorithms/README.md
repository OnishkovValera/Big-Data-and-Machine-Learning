# Базовые алгоритмы на графах

Представление графов и реализация базовых операций над ними. Работа охватывает переход от структуры данных к алгоритмам обхода и исследованию свойств графа.

## Содержание

- Вершины, рёбра и способы хранения графа.
- Обходы и достижимость.
- Вычислительная сложность и свойства полученных структур.
