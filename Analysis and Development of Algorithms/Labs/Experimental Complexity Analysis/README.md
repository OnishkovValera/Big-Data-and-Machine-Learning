# Экспериментальный анализ сложности

Экспериментальное исследование зависимости времени работы алгоритма от размера входных данных. Рассматриваются теоретические оценки и измерения на наборах разного объёма.

## Содержание

- Асимптотическая сложность и доминирующие операции.
- Размер входа, время выполнения и сравнение алгоритмов.
- Графики зависимости времени от размера задачи и интерпретация результатов.
