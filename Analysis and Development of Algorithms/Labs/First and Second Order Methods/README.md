# Методы первого и второго порядка

Безусловная нелинейная оптимизация с использованием производных. Рассматривается роль градиента и информации о кривизне функции при построении итерационных методов.

## Содержание

- Градиентные методы и выбор шага.
- Методы второго порядка и матрица Гессе.
- Поведение итераций, сходимость и сравнение вычислительных затрат.
