# Прямые методы нелинейной оптимизации

Поиск минимума функции без использования производных. Работа связывает постановку задачи безусловной оптимизации с экспериментальным сравнением прямых методов.

## Содержание

- Целевая функция, область поиска и начальное приближение.
- Прямой поиск и критерии завершения.
- Число вычислений функции, точность и вычислительные затраты.
