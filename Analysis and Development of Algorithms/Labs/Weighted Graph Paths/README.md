# Поиск путей во взвешенных графах

Исследование алгоритмов поиска маршрутов с учётом весов рёбер. Сравниваются модели задачи и поведение алгоритмов на графах разного типа.

## Содержание

- Кратчайший путь и стоимость маршрута.
- Dijkstra, Bellman–Ford и A*.
- Ограничения на веса, эвристики и сравнительная эффективность.
