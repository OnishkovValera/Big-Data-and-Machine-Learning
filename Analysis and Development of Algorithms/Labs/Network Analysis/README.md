# Инструменты анализа сетей

Анализ графа как модели сети взаимодействий. Работа объединяет структурные характеристики сети, программные инструменты и визуальное представление связей.

## Содержание

- Структура сети и характеристики вершин и связей.
- Сравнение сетевых характеристик.
- Визуализация графа и интерпретация результатов.
