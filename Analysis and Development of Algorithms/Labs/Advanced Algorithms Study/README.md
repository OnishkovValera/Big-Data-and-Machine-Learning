# Экспериментальное исследование современных алгоритмов

Углублённая работа по практическому анализу алгоритмов. Содержание объединяет описание задачи, алгоритмический подход и экспериментальное исследование его эффективности.

## Содержание

- Математическая и алгоритмическая постановка задачи.
- Сравнение подходов и вычислительных характеристик.
- Представление результатов экспериментов и обсуждение ограничений метода.
