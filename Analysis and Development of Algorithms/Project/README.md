# Курсовой проект по анализу алгоритмов

Проект объединяет постановку вычислительной задачи, описание алгоритмического решения и экспериментальную оценку эффективности. В материалах курса представлены отчёт, презентация и углублённая работа по анализу алгоритмов.

## Состав материалов

- Описание задачи и алгоритмического подхода.
- Экспериментальное исследование вычислительных характеристик.
- Представление результатов в отчёте и презентации.
