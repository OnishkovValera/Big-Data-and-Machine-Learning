# Домашние задания

[Описание предмета](../README.md)

Команды по 5–7 человек выполняют задания в контексте своего проекта. Результат — 1–5 слайдов и выступление представителя команды на 5–7 минут с ответами на вопросы. Темы работ связаны с разделами курса.

## Работы

- [Инновационный маркетинг проекта](Innovative-Marketing/README.md) — Работа раскрывает проблему клиента, емкость рынка, портрет целевой аудитории, существующих конкурентов и преимущества продукта.
