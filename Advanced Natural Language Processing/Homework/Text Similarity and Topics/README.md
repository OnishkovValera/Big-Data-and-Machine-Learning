# Подготовка текстов, близкие дубликаты и тематические модели

Домашняя работа ANLP 2022 с веб-текстами, шинглами и моделями тематической структуры корпуса.

## Содержание

- Удаление HTML и стоп-слов, стемминг и лемматизация.
- Поиск близких дубликатов через шинглы, MinHash и LSH.
- Тематические модели NMF, LDA и ARTM.
- Оценка качества тематических моделей.
