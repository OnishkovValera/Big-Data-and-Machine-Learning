# Домашние работы — материалы 2022 года

Задания ANLP 2022 по подготовке текстов, поиску близких дубликатов и обучению моделей текстового сходства.

## Содержание

- Очистка и нормализация веб-текстов.
- MinHash/LSH и тематические модели.
- Siamese LSTM, triplet loss и оценка качества поиска дубликатов.
