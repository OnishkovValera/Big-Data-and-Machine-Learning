# Практические занятия

Разработка и оценка систем обработки текста на основе LLM, поиска, агентов и дополнения внешними знаниями.

## Содержание

- Prompting, few-shot, структурированный вывод и интеграция с кодом.
- Инструменты, память и планирование LLM-агентов.
- Эмбеддинги, гибридный поиск, reranking и метрики поиска.
- RAG, сжатие контекста и графы знаний.
- SFT, PEFT, LoRA/QLoRA, RLHF/DPO и библиотеки transformers/unsloth.
- Мультимодальные модели, квантование, vLLM и дистилляция.
