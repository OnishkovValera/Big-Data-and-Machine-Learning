# Курсовая работа

Проектная часть объединяет инфраструктуру, обработку и хранение данных в прикладном решении.

## Содержание

- Сбор и подготовка данных для дальнейшего анализа или обучения моделей.
- Организация пакетной обработки и хранения данных.
- Связь инфраструктурных компонентов и представление результатов.

## Работы

- [Сбор изображений для обучения модели](Image%20Collection/README.md) — Курсовой проект по сбору изображений из материалов направления 2022–2024.
- [Климатические данные в распределённой инфраструктуре](Climate%20Data%20Pipeline/README.md) — Проект Dreamlone по обработке климатических данных с использованием облачной и распределённой инфраструктуры.
