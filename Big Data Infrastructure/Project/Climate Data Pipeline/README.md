# Климатические данные в распределённой инфраструктуре

Проект Dreamlone по обработке климатических данных с использованием облачной и распределённой инфраструктуры.

## Содержание

- Подготовка климатических наборов данных.
- Обработка в PySpark и AWS EMR.
- Хранение данных в Parquet.
- Прогнозирование и представление результатов в Dash.
