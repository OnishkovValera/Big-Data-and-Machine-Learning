# Big Data Infrastructure / Инфраструктура больших данных

Распределённые решения для обработки, хранения и защиты больших данных. Курс охватывает интеграционные платформы, пакетные и потоковые вычисления, отказоустойчивость и инструменты извлечения знаний из данных.

## Материалы курса

- [Лекции](Lectures/README.md).
- [Практические занятия](Practices/README.md).
- [Курсовой проект](Project/README.md).

## Что изучают

- Эволюция систем обработки больших данных и их основные типы.
- HDFS: распределённая файловая система, репликация и отказоустойчивость.
- MapReduce и обеспечение отказоустойчивости с Apache ZooKeeper; среди тем указаны согласование и Paxos.
- Управление ресурсами: YARN и Mesos, централизованное и двухуровневое планирование.
- Пакетная обработка данных в Apache Spark.
- Потоковая обработка: Apache Kafka, Apache Flink и Spark Streaming.
- Интерактивная обработка: архитектуры Lambda/Kappa и Spark SQL.
- Представление и обработка графовых данных в Spark GraphX.

## Подготовка

Функциональная парадигма Scala, Python, JavaScript и основы инфраструктуры хранения и обработки Big Data.
