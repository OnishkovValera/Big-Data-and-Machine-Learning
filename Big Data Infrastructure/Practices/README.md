# Практические занятия

Работа с распределённой инфраструктурой и инструментами обработки больших данных: вычислительный кластер, Spark и аналитическое хранение.

## Содержание

- Контейнерная инфраструктура и подключение к кластеру.
- Пакетная обработка данных с PySpark.
- Аналитическое хранение данных в ClickHouse.
- Потоковая обработка, отказоустойчивость и интеграция компонентов инфраструктуры.

- [Обработка данных в PySpark](PySpark/README.md) — Практическая работа с Apache Spark через Python в материалах 2022–2024.
- [Аналитическое хранение в ClickHouse](ClickHouse/README.md) — Практическая работа с ClickHouse как компонентом инфраструктуры больших данных.
