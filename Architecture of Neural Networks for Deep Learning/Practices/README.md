# Практические занятия

Построение, обучение и оценка нейросетевых архитектур. Учебные материалы включают компьютерное зрение, генеративные модели и обучение с подкреплением.

## Содержание

- Работа с PyTorch и подготовка данных для нейросетевого эксперимента.
- Сегментация изображений и оценка результатов.
- Генеративные сети DCGAN.
- Обучение агента PPO в среде Walker2D.
- Дополнительные материалы по pruning нейросетей.

## Работы

- [Сегментация изображений](Image%20Segmentation/README.md) — Лабораторная тема по сегментации изображений в материалах курса 2022–2024.
- [Генерация изображений с DCGAN](DCGAN/README.md) — Лабораторная тема по генеративно-состязательной сети DCGAN из материалов курса 2022–2024.
- [Walker2D и PPO](Walker2D%20PPO/README.md) — Лабораторная работа курса нейросетей ИТМО 2022 года: обучение агента в среде Walker2D.
