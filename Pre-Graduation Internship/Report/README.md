# Отчёт по преддипломной практике

Описание выполненного проекта, использованных технологий и полученных результатов. Отчётные материалы загружаются в ИСУ.

## Структура

1. Титульный лист.
2. Обзор литературы.
3. Цель и задачи практики.
4. Сведения об организации.
5. Описание выполненного проекта.
6. Использованные технологии.
7. Экспериментальные результаты.
8. Анализ результатов и выводы.
9. Список источников.
10. Приложения.

В состав дополнительных материалов могут входить презентация, дневник практики, отзыв, тезисы или черновик статьи — в зависимости от индивидуального задания.
