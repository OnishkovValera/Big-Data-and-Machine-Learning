# Поиск и анализ научной литературы

Тематическая группа практических занятий по работе с научно-технической информацией, публикациями и реферативными базами.

## Содержание

- Поиск научно-технической информации.
- Работа с научными публикациями.
- Реферативные и международные наукометрические базы.
- Связь обзора литературы с исследовательским вопросом.
