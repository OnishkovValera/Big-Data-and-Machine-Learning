# Научный текст и публикация

Тематическая группа практических занятий о структуре научного текста и подготовке результатов к публикации.

## Содержание

- Принципы построения научного текста.
- Изложение постановки задачи, методов и результатов.
- Подготовка научной публикации.
- Связь текста с материалами проведённого исследования.
