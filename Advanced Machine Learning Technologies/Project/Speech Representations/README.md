# Сравнение речевых представлений ContentVec и HuBERT

Курсовой проект по сопоставлению ContentVec и HuBERT в двух задачах обработки речи.

## Содержание

- Распознавание речи на AMI.
- Оценка распознавания по Word Error Rate (WER).
- Верификация диктора на VoxCeleb.
- Оценка верификации по Equal Error Rate (EER).
