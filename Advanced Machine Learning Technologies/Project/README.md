# Курсовая работа

Прикладное исследование специализированных методов машинного обучения с сопоставлением моделей и оценкой качества.

## Содержание

- Выбор прикладной задачи и семейства моделей.
- Экспериментальное сравнение представлений и архитектур.
- Оценка качества на метриках целевой задачи.
- Интерпретация результатов и организация исследовательского проекта.
