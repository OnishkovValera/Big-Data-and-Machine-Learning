# Лабораторные работы

Практическая реализация нейросетевых методов для изображений, последовательностей, текста и генерации данных.

## Содержание

- Обучение нейросетей: функции потерь, backpropagation, оптимизаторы и контроль качества.
- Свёрточные и рекуррентные архитектуры, attention и Transformers.
- Автоэнкодеры, VAE, GAN и conditional GAN.
- Текстовые признаки, эмбеддинги и тематическое моделирование.
- Методы обучения с подкреплением и интерпретации моделей.
