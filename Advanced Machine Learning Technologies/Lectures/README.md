# Лекции

Advanced Machine Learning Technologies / Специализированные технологии машинного обучения

Нейросетевые методы для изображений, видео, текста, генерации новых объектов и обучения с подкреплением. Теория сопровождается интенсивной практикой по алгоритмам глубокого обучения.

## Содержание

- Перцептрон и многослойные сети, функции активации и потерь, backpropagation, инициализация весов и проблемы градиентов.
- Обучение и валидация: train/test/validation, мониторинг, mini-batch SGD, momentum, RMSProp, Adam, параллельная настройка гиперпараметров.
- CNN: свёртка, pooling/padding, VGG-16, ResNet, attention и капсульные сети.
- Последовательности: RNN, LSTM, GRU, multi-head attention и Transformers.
- Автоэнкодеры, VAE, GAN и conditional GAN, генерация 3D-объектов и перенос стиля.
- NLP: bag of words, TF-IDF, стемминг/лемматизация, word2vec, тематическое моделирование LDA и оценка качества тем.
- RL: марковский процесс принятия решений, Q-learning и REINFORCE.
- Компьютерное зрение: 3D-детекция и применения глубокого обучения в беспилотных системах.
