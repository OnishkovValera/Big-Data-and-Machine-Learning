# Итоговое тестирование

[К разделу](../README.md) · [Описание предмета](../../README.md)

Тест охватывает ценности ИТМО, организацию обучения, научные возможности, карьерные и университетские сервисы. Формат — 30 вопросов; для прохождения требуется 25 правильных ответов.
