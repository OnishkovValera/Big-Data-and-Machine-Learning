# Финальная переговорная игра

[К разделу](../README.md) · [Описание предмета](../../README.md)

Игра моделирует многосторонние переговоры и командную работу в переговорном процессе. Практика объединяет подготовку целей и стратегии, взаимодействие участников и обсуждение результатов.
