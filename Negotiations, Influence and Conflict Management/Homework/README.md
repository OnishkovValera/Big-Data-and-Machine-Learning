# Домашние задания

[Описание предмета](../README.md)

Семь домашних работ закрепляют инструменты переговоров и анализа конфликтов. Задания включают выбор объективных критериев, распознавание типов аргументов, проверку понимания ключевых понятий и применение изученных стратегий.
