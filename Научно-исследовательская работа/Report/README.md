# Отчёт по НИР

Отчёт описывает исследовательскую задачу, выполненные работы и полученные результаты. Материалы оформляются в модуле «Практика» ИСУ вместе с артефактами проекта.

## Содержание отчёта

- Тема исследования, цель и задачи.
- Использованные научные источники и существующие подходы.
- Применённые методы, данные и программные инструменты.
- Выполненные работы и результаты экспериментов.
- Анализ результатов и выводы.
- Исследовательские артефакты: код, модели, данные, графики и другие материалы проекта.
