# Исследовательский проект

Исследовательская работа объединяет постановку проблемы, анализ существующих подходов, разработку решения и оценку результатов.

## Содержание

- Формулировка исследовательской задачи и её связи с практической проблемой.
- Обзор научных публикаций и существующих технических решений.
- Выбор методов, моделей и программных инструментов.
- Планирование вычислительных экспериментов.
- Разработка алгоритмов, моделей или исследовательского прототипа.
- Сбор результатов, анализ ограничений и формулировка выводов.

## Примеры проектов

- [Transformer-чатбот](https://github.com/zer0deck/transformer_chatbot): эмоциональная составляющая диалоговой модели, предобработка данных и эксперименты.
- [Калибровка синтетических табличных данных](https://github.com/GennadiiFilatov/tabular-synth-calibration): генераторы данных, калибровка и оценка качества.
- [Шаблон проекта НИР](https://github.com/Industrial-AI-Research-Lab/nir-project-template): структура Python-проекта, конфигурации экспериментов, MLflow, тесты и CI.
- [Методические материалы по исследовательским проектам](https://github.com/Industrial-AI-Research-Lab/project-implementation-manual).
