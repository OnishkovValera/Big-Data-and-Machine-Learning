# Климатические данные и прогноз урожайности

Проект Dreamlone посвящён подготовке климатических данных и прогнозированию урожайности пшеницы и кукурузы. В репозитории объединены обработка пространственно-временных данных и несколько прогнозных подходов.

## Содержание

- Подготовка климатических данных в формате NetCDF.
- Преобразование и объединение данных для дальнейшего анализа.
- Линейная регрессия, ARIMA, фильтр Калмана и марковская модель.
- Ноутбуки прогнозирования урожайности пшеницы и кукурузы.
