# Сравнительная оценка методов анализа данных

Сопоставление аналитических методов и прогнозных моделей на основе статистических критериев. Рассматриваются качество, устойчивость и значимость различий результатов.

## Содержание

- Параметрические и непараметрические сравнения.
- Доверительные интервалы и множественные сравнения.
- Байесовский выбор моделей и интерпретация различий.
