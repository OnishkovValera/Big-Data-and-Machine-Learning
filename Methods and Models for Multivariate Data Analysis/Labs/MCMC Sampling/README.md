# Семплирование методом MCMC

Получение выборки из вероятностной модели с помощью марковской цепи. Метод связывает заданное распределение с последовательностью зависимых случайных состояний.

## Содержание

- Целевое распределение и переходы марковской цепи.
- Алгоритм Metropolis–Hastings.
- Стационарность, эргодичность и свойства полученной выборки.
