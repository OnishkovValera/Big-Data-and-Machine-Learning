# Одномерный анализ для улучшения качества данных

Анализ отдельных признаков и их распределений. Работа посвящена статистическим характеристикам выборки и связи этих характеристик с качеством исходных данных.

## Содержание

- Эмпирическое распределение, моменты и квантили.
- Статистическое оценивание и сравнение наблюдений.
- Интерпретация распределений и особенностей отдельных признаков.
