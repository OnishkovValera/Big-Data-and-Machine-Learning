# Поиск выбросов и аномалий в многомерной выборке

Исследование наблюдений, отличающихся от основной структуры многомерных данных. Работа связывает понятие аномалии с выбранной моделью распределения и зависимостями между признаками.

## Содержание

- Одномерные и многомерные отклонения.
- Влияние зависимости признаков на выделение аномалий.
- Интерпретация нетипичных наблюдений и устойчивость модели.
