# Многомерный анализ для улучшения качества данных

Совместное исследование нескольких признаков. Рассматриваются зависимости между переменными, структура многомерной выборки и представление данных с помощью статистических моделей.

## Содержание

- Векторы средних и ковариационные матрицы.
- Корреляции и совместные распределения.
- PCA, факторные представления и интерпретация структуры данных.
