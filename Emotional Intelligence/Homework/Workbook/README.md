# Workbook: эмоциональные компетенции

[К разделу](../README.md) · [Описание предмета](../../README.md)

Рабочая тетрадь заполняется в течение курса и содержит кейсы, чек-листы и рефлексию. Начальный профиль оценивает уровень эмоциональных компетенций и приоритеты их развития. Итоговое портфолио включает выводы по материалам и цели совершенствования командной работы и общения.
