# Курсовой проект

Построение и исследование непрерывной модели прикладного процесса: выбор математического аппарата, настройка параметров и интерпретация динамики.

## Содержание

- Формализация процесса системой дифференциальных уравнений.
- Аналитическое и численное исследование поведения модели.
- Равновесия, устойчивость и фазовый портрет.
- Настройка модели по данным и анализ результатов.
