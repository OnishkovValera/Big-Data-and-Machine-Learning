# Модель Лотки–Вольтерры

Проект по моделированию взаимосвязанных популяций и настройке параметров на данных hare/lynx.

## Содержание

- Система Лотки–Вольтерры.
- Численное интегрирование с solve_ivp и odeint.
- Оценивание параметров через differential_evolution и curve_fit.
- Сопоставление результатов модели с наблюдениями.
