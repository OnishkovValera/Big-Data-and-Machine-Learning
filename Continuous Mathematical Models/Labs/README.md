# Лабораторные работы

Аналитическое и численное исследование непрерывных математических моделей, динамических систем и дифференциальных уравнений.

## Содержание

- Построение моделей на основе ОДУ и систем ОДУ.
- Аналитическое решение дифференциальных уравнений.
- Методы Эйлера, Эйлера–Коши, Рунге–Кутта и Адамса.
- Равновесия, фазовые портреты, устойчивость и интерпретация результатов.

## Работы

- [Аналитическое решение ОДУ](Analytical%20ODE%20Solutions/README.md) — Работа по аналитическому исследованию непрерывных моделей и решению обыкновенных дифференциальных уравнений.
- [Численное решение ОДУ](Numerical%20ODE%20Solutions/README.md) — Работа по компьютерному исследованию моделей, заданных дифференциальными уравнениями.
