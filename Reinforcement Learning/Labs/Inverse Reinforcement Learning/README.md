# Обратное обучение с подкреплением

Восстановление функции награды по поведению эксперта на задаче перемещения в Grid World.

## Содержание

- Постановка inverse reinforcement learning.
- Экспертные траектории как данные о предпочтительном поведении.
- Метод maximum entropy IRL.
