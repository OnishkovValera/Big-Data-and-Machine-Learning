# Лабораторные работы

Реализация и исследование обучения агентов: взаимодействие со средой, выбор стратегии, функция награды и оценка поведения.

## Содержание

- Алгоритмы DQN и PPO; настройка среды для экспериментов.
- Stable-baselines3, RLlib и Unity ML-Agents.
- Сохранение результатов и анализ качества обучения.
- Обучение в симуляции, внутренняя мотивация и иерархические методы.

## Работы

- [Основы RL на CartPole](CartPole/README.md) — Практикум с моделью CartPole для изучения базовых идей обучения с подкреплением.
- [Обратное обучение с подкреплением](Inverse%20Reinforcement%20Learning/README.md) — Восстановление функции награды по поведению эксперта на задаче перемещения в Grid World.
- [Многоагентное обучение в футбольной среде](Multi-Agent%20Soccer/README.md) — Практикум по марковским играм и многоагентному обучению на футбольной модели Литтмана.
- [Обучение с обратной связью человека](Human%20Feedback/README.md) — Практикум по RLHF: использование человеческой обратной связи в обучении агента или языковой модели.
