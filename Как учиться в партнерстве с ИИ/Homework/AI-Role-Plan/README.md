# План использования роли ИИ

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа описывает реальную учебную задачу и выбранную роль ИИ, разделяет самостоятельную и делегируемую работу. План включает 2–3 промпта, требования к приватности, процедуру проверки и анализ рисков. Один запрос апробируется с кратким разбором результата.
