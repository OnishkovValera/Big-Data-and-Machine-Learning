# Чек-лист выбора ИИ-инструмента

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа формирует личный чек-лист выбора сервиса и подборку инструментов для профильных дисциплин. Критерии включают качество и достоверность ответа, работу с файлами, приватность и пригодность для конкретных задач.

## Ресурсы

- [Страница дисциплины](https://my.itmo.ru/programs/59900).
