# Домашние задания

[Описание предмета](../README.md)

Четыре домашних задания посвящены применению ИИ в собственном учебном контексте. Работы сопровождаются описанием сервисов, запросов, проверки результатов и самостоятельного вклада.

## Работы

- [План использования роли ИИ](AI-Role-Plan/README.md) — Работа описывает реальную учебную задачу и выбранную роль ИИ, разделяет самостоятельную и делегируемую работу.
- [Чек-лист выбора ИИ-инструмента](Tool-Selection-Checklist/README.md) — Работа формирует личный чек-лист выбора сервиса и подборку инструментов для профильных дисциплин.
- [Кодекс использования ИИ](Responsible-AI-Code/README.md) — Работа формулирует 5–7 правил ответственного использования ИИ в обучении с обоснованием каждого.
- [Границы применения ИИ в учебном задании](Academic-Task-Boundaries/README.md) — Работа разбирает задание текущего семестра: допустимые способы использования ИИ, форму раскрытия его участия и механизм самопроверки.
