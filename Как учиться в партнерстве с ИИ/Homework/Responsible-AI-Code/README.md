# Кодекс использования ИИ

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа формулирует 5–7 правил ответственного использования ИИ в обучении с обоснованием каждого. Правила связаны с академической добросовестностью, авторством, раскрытием применения ИИ и проверкой результатов.
