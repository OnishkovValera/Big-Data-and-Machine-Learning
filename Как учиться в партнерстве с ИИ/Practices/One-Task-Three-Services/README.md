# Одна задача — три сервиса

[К разделу](../README.md) · [Описание предмета](../../README.md)

Одинаковый запрос выполняется в трех сервисах. Ответы сравниваются по достоверности, полноте, качеству русского языка и удобству. Итог связывает различия инструментов с классами учебных задач.

## Ресурсы

- [Страница дисциплины](https://my.itmo.ru/programs/59900).
