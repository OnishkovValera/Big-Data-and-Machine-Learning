# Разбор галлюцинации

[К разделу](../README.md) · [Описание предмета](../../README.md)

Группа анализирует ответ ИИ с фактической ошибкой, логическим сбоем и вымышленной ссылкой. Результат включает найденные ошибки, их классификацию и объяснение возможных причин.
