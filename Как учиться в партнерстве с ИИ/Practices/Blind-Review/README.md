# Слепая экспертиза

[К разделу](../README.md) · [Описание предмета](../../README.md)

Сравниваются три ответа на один учебный вопрос: сгенерированный ИИ, отредактированный человеком ответ ИИ и текст преподавателя. Участники определяют авторство и обсуждают надежность признаков, использованных при оценке.

- [Страница дисциплины](https://my.itmo.ru/programs/59900).
