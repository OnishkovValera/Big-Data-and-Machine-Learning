# Итоговая практическая работа

[Описание предмета](../README.md)

Итоговая работа решает реальную учебную задачу: разбор темы, подготовку текста, работу с кодом, статьей или выступлением. Результат включает продукт, историю взаимодействия с ИИ и рефлексию на 1–2 страницы.

## Состав работы

- Готовый результат решения выбранной задачи: текст, код, конспект, план подготовки или презентация.
- История взаимодействия: использованные сервисы и модели, ключевые запросы и их уточнения.
- Рефлексия: польза ИИ, выявленные ошибки, способы проверки, самостоятельная часть и соблюдение академической добросовестности.
