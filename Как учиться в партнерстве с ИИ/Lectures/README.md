# Лекционные материалы

[Описание предмета](../README.md)

Теоретическая часть посвящена ролям генеративного ИИ в учебе, выбору инструментов, проверке результатов и академической добросовестности. Рассматриваются ограничения языковых моделей и ответственность за подготовленный материал.

## Темы

- Генеративный ИИ и языковые модели: возможности, ограничения и отличие от поиска.
- Роли ИИ: тьютор, ассистент, критик, редактор и генератор идей.
- Практическое сравнение сервисов по качеству ответа, доступности, работе с файлами и приватности.
- Проверка фактов, логики, вычислений и ссылок; обнаружение галлюцинаций.
- Этика ИИ, академическая добросовестность и раскрытие использования ИИ в ИТМО.
- Личные правила работы с ИИ и набор промптов для своих дисциплин.
