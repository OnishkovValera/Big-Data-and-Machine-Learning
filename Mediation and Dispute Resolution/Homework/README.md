# Домашние задания

[Описание предмета](../README.md)

Письменные работы включают планирование медиации, чек-листы активного слушания, анализ кейсов и рефлексию. Они связывают инструменты курса с личными и профессиональными ситуациями.

## Работы

- [План медиации](Mediation-Plan/README.md) — Письменная работа включает план процедуры, вступительное слово посредника, предполагаемые интересы сторон и способы их выявления.
- [Практика активного слушания](Active-Listening/README.md) — Работа анализирует разговор с использованием чек-листа активного слушания.
