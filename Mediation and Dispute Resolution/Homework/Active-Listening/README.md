# Практика активного слушания

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа анализирует разговор с использованием чек-листа активного слушания. Оцениваются внимание, вопросы, отсутствие перебиваний, перефразирование и отношение к эмоциям собеседника. Результат включает рефлексию о ходе общения.
