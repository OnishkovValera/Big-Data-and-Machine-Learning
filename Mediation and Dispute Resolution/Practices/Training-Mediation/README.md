# Учебная медиация

[К разделу](../README.md) · [Описание предмета](../../README.md)

Участники распределяются на стороны спора и посредника. Подготовка включает изучение позиций и предполагаемых интересов; затем проводится медиационная сессия и обсуждаются ее результаты. Медиатор организует процесс, сохраняя нейтральность.
