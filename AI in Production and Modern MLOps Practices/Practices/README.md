# Практические занятия

Инженерная организация полного цикла ML-системы: воспроизводимое обучение, публикация модели, наблюдаемость и обновление в эксплуатации.

## Содержание

- Docker и управление вычислительным окружением.
- MLflow и отслеживание экспериментов; версионируемый пайплайн обучения.
- Упаковка модели, real-time/batch/streaming и API REST/gRPC с FastAPI.
- Оркестрация вычислений средствами Kubeflow Pipelines и Airflow.
- Метрики, логи, оповещения, data/concept drift, shadow deployment и A/B-тестирование.
- Feature stores, автоматизация CI/CD и переобучения, безопасность и стоимость инфраструктуры.
- Сервинг и оптимизация LLM, RAG, распределённые вычисления с Ray и SLAMA.
