# Презентация магистерской работы

[К разделу](../README.md) · [Описание предмета](../../README.md)

Итоговая презентация посвящена теме ВКР и содержит не менее десяти слайдов и трех источников. Доклад длится около десяти минут и сопровождается ответами на вопросы. Содержание раскрывает актуальность, цель, задачи, новизну и значимость исследования.
