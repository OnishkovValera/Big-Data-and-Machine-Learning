# Домашние задания

[Описание предмета](../README.md)

Домашние задания посвящены чтению и письму в научной сфере, профессиональной терминологии, библиографии и оформлению цитат. Работы связываются с направлением подготовки магистранта.

## Работы

- [Библиография по профессиональной теме](Bibliography/README.md) — Работа включает подбор не менее пяти источников по теме профессиональной области и оформление библиографического списка в алфавитном порядке.
- [Цитирование определений терминов](Terms-Citation/README.md) — Определения терминов профессиональной области оформляются как цитаты разными способами.
