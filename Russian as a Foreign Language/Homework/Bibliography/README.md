# Библиография по профессиональной теме

[К разделу](../README.md) · [Описание предмета](../../README.md)

Работа включает подбор не менее пяти источников по теме профессиональной области и оформление библиографического списка в алфавитном порядке. Связанные навыки — поиск научной информации и оформление источников.
